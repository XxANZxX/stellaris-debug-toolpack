# Debug Toolpack 10.9.9 для Stellaris 4.5.x

Окно инструментов администратора для одиночной игры и мультиплеера. Версия мода 10.9.9, игра 4.5.2 «Cygnus». DLC не нужны.

## Установка

1. **Удалите старую папку** `mod/dtp_toolpack` целиком.
2. Распакуйте архив в `Документы/Paradox Interactive/Stellaris/mod/`.
3. Включите мод в лаунчере.

Если в окне нет трёх колонок (разделы со значками слева, инструменты в центре, панель «Цель / Число / Срок / Итог» справа), значит, запущена старая версия.

## Стиль 7.1 — свои текстуры в духе Stellaris

Все текстуры окна мод рисует сам; генератор — `tools/art3.py`.

- **Форма панелей и кнопок.** Скошенные углы, как у окон игры. Тёмные сине-зелёные панели с лёгким зерном и мягкой виньеткой. Двойная светящаяся бирюзовая кромка, светлая линия сверху и свечение снизу. Оранжевые угловые скобки на окне и плашке.
- **Значки.** Разделы — в шестиугольниках; выбранный раздел — янтарная плашка с полосой слева. A и B — шестиугольные значки. В углу шапки гексагональный узор, логотип тоже шестигранник.
- **Цвет кнопки показывает назначение:**
  - зелёно-бирюзовая — главное действие;
  - тёмная бирюзовая — обычное;
  - янтарная — включено или особое;
  - красная — разрушительное.

  У каждой кнопки свой вид в покое, при наведении (подсвечивается) и при нажатии.
- **Заголовки** — крупные, золотые, шрифтом заголовков игры.

## 10.7.7 — навигатор по карте (своя система отметки, и для ничьих систем)
- Вкладка «Системы» → **«Навигатор по карте →»** (справа внизу списка). Курсор стоит на системе (сначала — ваша столица), ниже кнопки всех соседних систем по гиперлиниям (до 12; отмеченные — с красной точкой). Клик по соседу — курсор переходит туда; **«● Отметить» / «✕ Снять отметку»** — для системы под курсором, в т. ч. ничьей.
- Быстрые переходы: «⌂ К моей столице», «К столице A», «К системе планеты P». «← Список отметок» — назад к списку.
- Почему так: свои кнопки на значках карты игра не связывает с системой (проверено), а «+» претензий рисует только движок и только на чужих системах.

## 10.7.6
- **Серые кольца не снимались** при выключении «Режима отметки» (а красные — при снятии отметки): в 4.5.2 проверка класса звезды не узнаёт классы-копии мода. Теперь исходный класс звезды запоминается флагом системы и возвращается по нему. Кольца, оставшиеся в старой тестовой партии от 10.7.5, этим не снимутся — проверяйте в новой партии.
- **Подсказки кнопок без «Устанавливает переменную …»**: у всех кнопок мода эффект скрыт от автоматической подсказки игры (своя подсказка у каждой кнопки есть).
- **«Отметка претензией»** работает только на системах других держав: на ничьих и своих игра «+» не показывает (проверено на скриншоте 22.10 — ограничение движка, правилом не снимается).

## 10.7.5
- «Отметка претензией» не срабатывала: отдельный файл с правилом претензий игра не брала (у правил при совпадении имени побеждает файл игры). Теперь мод заменяет весь файл правил игры `common/game_rules/00_rules.txt` — дословная копия 4.5.2, изменено только правило `can_add_claim` (6 строк).
- Включение режима пишет в game.log строку `DTP CLAIMMARK: mode ON`.
- Конфликт: моды, которые тоже заменяют `common/game_rules/00_rules.txt`, будут спорить с этим файлом (побеждает тот, что ниже в списке).

## 10.7.4 — «Отметка претензией» и на ничьих системах
- Мод заменяет правило игры `can_add_claim`: пока у ведущего включён режим «Отметка претензией», для него сняты все ограничения на претензии (политика «неограниченные войны», ничьи системы и т. п.). Для остальных игроков правило — дословная копия игры.
- Поиск новой претензии больше не требует владельца системы; запасной путь — претензии превращаются в отметки и при открытии вкладки «Системы»/«Обновить список».
- Если в игре есть жёсткое (не скриптовое) ограничение и «+» на ничьей системе всё же не появится — окно звезды и Alt+M.
- Конфликт: моды, которые тоже меняют `can_add_claim`, будут спорить с этим файлом.

## 10.7.3 — отметка кликом по большой карте через «Претензии»
- Корабль-маркер из 10.7.2 убран.
- Вкладка «Системы» → **«Отметка претензией: ВКЛ»**. Затем режим карты «Претензии» → «+» на системе **другой державы** прямо на большой карте → система сразу отмечена (на паузе, бесплатно), претензия тут же убирается. Повторный «+» на отмеченной — снять.
- Как работает: игра вызывает `on_claim_system`, мод находит систему с новой претензией ведущего, ставит/снимает отметку и удаляет претензию. Настоящие претензии ведущего, сделанные до включения режима, не трогаются.
- Ничьи и свои системы игра претензией отметить не даёт — для них окно звезды и Alt+M.

## 10.7.1 — отметки, которые видит только ведущий
- **Клик прямо по значку системы на большой карте невозможен** — проверено в игре 4.5.2 (game.log: `DTP MAPCLICK | this=from=root=держава игрока`): игра не говорит кнопке, над какой она системой. Точки на карте убраны, mapicons.gui мод больше не меняет.
- **«Метки только для меня»** (вкладка «Системы»): над каждой отмеченной системой на большой карте — значок точки интереса, который видит только включивший (до 30 систем, список — в журнале ситуаций «Отметки ведущего»).
- **«Красить звёзды: ВКЛ/ВЫКЛ»**: выключено — звёзды не перекрашиваются, другие игроки отметок не видят вообще.
- **«Открыть мне всю карту»** — все системы становятся посещёнными для вашей державы; **«Изучить мне все планеты»** — все планеты исследованы. Только для нажавшего.

## 10.7.0 — отметка кликом по большой карте (проверка)
- При включённом «Режиме отметки на карте» рядом с названием каждой системы на галактической карте появляется кнопка:
  - **серая точка** — система не отмечена, клик — отметить; **красная** — отмечена, клик — снять. Отметка сразу попадает в список «Отмечено систем».
  - **жёлтый «?»** — игра не передаёт кнопке систему (так было в 3.7), кликом по карте отмечать нельзя → Alt+M в окне звезды/планеты.
- В game.log каждый клик пишет строку `DTP MAPCLICK` — по ней видно, что игра дала кнопке.

## 10.6.9 — режим отметки на большой карте
- Вкладка «Системы» → **«Режим отметки на карте: ВКЛ/ВЫКЛ»**. Включён — на большой галактической карте у всех систем (и ничьих) серое кольцо вокруг звезды, у отмеченных — красное. Выключен — обычные звёзды, отмеченные остаются красными. Кольца видят все игроки.
- Отметить систему: откройте её звезду или любую планету (в т. ч. в ничьей системе) и нажмите Alt+M — система попадает в список отмеченных («Отмечено систем: N») и все действия «Со всеми отмеченными».
- Почему нельзя кликнуть прямо по значку на карте: игра даёт кнопкам в значках карты только державу игрока, а не систему (проверено в game.log), поэтому отметка — через окно звезды/планеты.

## 10.6.8 — пометка «только игроки»
- В подсказках кнопок, которые действуют **только на живых игроков**, есть отдельная строка: «● Только живые игроки — державы ИИ не затрагиваются» (ресурсы всем игрокам, + в месяц всем, пакет поддержки, ремонт, перемирие, контакт, границы, отношения, сводка) или «● Только между живыми игроками — войны с ИИ и между ИИ идут как обычно» (общий запрет войн и личные правила).
- Английский перевод проверен целиком: 3959 из 3959 строк, без кириллицы, цвета и подстановки совпадают с русским.

## Совместимость с UI Overhaul Dynamic (10.6.1)
В архиве два мода:
- `dtp_toolpack` — сам Toolpack, работает с обычным интерфейсом игры;
- `dtp_toolpack_uiod` — патч «Debug Toolpack — UI Overhaul Dynamic patch», только для тех, у кого включён UIOD.

**Без UIOD:** включите только Debug Toolpack (DTP), патч не нужен.
**С UIOD:** включите все три мода в таком порядке — UI Overhaul Dynamic → Debug Toolpack (DTP) → патч **последним**.

Патч собран из файлов UIOD `main.gui`, `planet_view.gui`, `fleet_view.gui`, `starbase_view.gui`. Окна UIOD в нём не изменены ни на строку, в них только добавлены панели Toolpack. Расположение подогнано под UIOD:
- кнопка Toolpack опущена под верхнюю панель UIOD;
- панель на экране планеты стала компактнее и стоит на картинке планеты;
- панель флота — справа от окна флота;
- панель станции — на картинке станции.

Все панели можно перетаскивать. Если UIOD обновится и что-то съедет, пересоберите патч: `python3 tools/make_uiod_patch.py <папка UIOD> <interface игры> <common игры> <gfx/map/map игры> <куда>`.

- **Таймер сессии:** «1 год … 5 лет» игрового времени. Всем окно с годом окончания; за месяц до конца — «Сессия скоро закончится»; в конце — «Сессия окончена: ставим паузу и сохраняемся». «Отменить таймер» — снять. Поставить игру на паузу скрипт не может — это делает ХОСТ.

## Что нового в 9.5 — запрет блокирует кнопку «Объявить войну»
- Пока действует запрет, у игрока кнопка «Объявить войну» против другого игрока **серая**, а в подсказке написано, почему:
  - общий запрет — «Запрещено ведущим партии: войны между игроками сейчас запрещены»;
  - личный запрет державе — «вашей державе лично запрещено объявлять войну игрокам»;
  - защита — «эта держава под защитой ведущего — на неё нельзя нападать».
- Войны с ИИ общий и личный запрет не блокируют. На защищённую державу не может напасть ни один игрок.
- Слежение за войнами осталось: если война всё же началась другим путём (союзники, федерация, сюзерен) — всем окно «Нарушение правил партии», у ведущего — санкции.
- **Совместимость (с 9.8):** мод больше не подменяет весь игровой файл дипломатии. Дипломатические действия в Stellaris работают по правилу «последний загруженный побеждает», поэтому мод кладёт только блок «Объявить войну» в отдельный файл `zz_dtp_declare_war.txt`. Конфликт возможен только с модами, которые меняют именно объявление войны.

## Что нового в 9.4 — запрет для всей галактики или для одной державы
- «Правила партии» теперь различают два уровня:
  - **Вся галактика** — «Вся галактика: запрет на N г.», «Вся галактика: бессрочно», «Снять общий запрет» (как раньше).
  - **Держава A лично** (выбрана в карточке сверху): «A не нападает на игроков: N г.» — только ей нельзя объявлять войну игрокам; «Защита A: N г.» — игрокам нельзя нападать на неё (например, защита новичка). «Снять с A личные правила» убирает оба.
- Строка под заголовком показывает состояние A: «нападать на игроков нельзя до 2240» / «под защитой до 2240».
- Срок берётся из того же поля ввода. Личные правила работают и без общего запрета.
- Нарушение личного запрета или защиты ловится так же, как общего: всем окно, у ведущего — «Унизить» / «Простить».
- Всем игрокам приходят окна: о личном запрете, о защите, о снятии и об окончании срока.

## Что нового в 9.3 — срок запрета войн вводится вручную

## Что нового в 9.1 — контроль правила «войны между игроками запрещены»

## Клавиатура и самопроверка (8.5)

**Набор числа с клавиатуры.**

- Кнопка «Клавиатура» в панели «Число» переключает режим. В режиме «только Alt+цифра» число набирается через Alt+1…Alt+0 — на такие сочетания игра не реагирует.
- Для клавиш NumPad добавлены пробные имена: NUMPAD0, NUMPAD_0, KP0, NUM_0. Какие из них знает игра, будет видно по error.log: лишние имена дают строку «Could not find matching key» и больше ни на что не влияют.

**Самопроверка (раздел «Журнал»).** Четыре теста; каждый сам возвращает всё как было, итог показывается в строке итога и пишется в game.log как `DTP TEST …: OK/FAIL`:
- бонус выбранной планеты;
- бонус державы A (модификатор игры);
- отметка системы;
- ресурсы A.

  - **отмеченные системы** — их число.

  Там, где нужен получатель (Держава, Дипломатия, Системы, Планета, Флот), справа в карточке — **B** со своей кнопкой «Сменить →».
- **Инструменты разбиты на смысловые группы** с заголовками, например «Тип планеты», «Особые типы», «Природа и размер». Кнопки крупные (высота 30), рамок вокруг групп нет — только заголовок и тонкая линия.
- **Панель «Число» и «Срок»** открыта только там, где числа нужны: «Ресурсы», «Модификаторы», «Главная». В остальных разделах инструменты занимают всю ширину.
- **Строка итога** под рабочей областью, цвет показывает результат:
  - зелёная — «ГОТОВО»;
  - красная — «ОТКАЗАНО» (нет права);
  - оранжевая — «НЕ ВЫПОЛНЕНО» (нет цели).

  На её месте появляется подтверждение опасных действий: «ПОДТВЕРДИТЬ» и «Отмена».
- **Главная** — стартовая точка:
  - карточка цели;
  - «Разделы» — шесть плиток со значками;
  - «Быстро» — + ресурсы державе A;
  - «Недавнее» — повтор последнего действия, журнал, отмеченные системы;
  - «Режим» — принудительный режим.

Разрушительные и массовые действия требуют второго нажатия: появляется красная строка «ПОДТВЕРДИТЬ». После выполнения подтверждение сбрасывается, так что случайный повтор невозможен.

## Отметка систем

**Как отметить:**
- Откройте окно планеты или звезды системы, либо кликните по значку станции прямо на галактической карте.
- Затем нажмите **Alt+M** или кнопку «● ОТМЕТИТЬ» на полосе Toolpack. Повторное Alt+M снимает отметку.
- Много систем сразу: вкладка «Системы» → «Все системы A» или «Расширить на соседние».

**Как отметка видна на галактической карте:**
1. Система переименовывается в «»» Имя ««». Снятие отметки возвращает имя: оно берётся у звезды системы, а звезда носит исходное имя.
2. Звезда становится красной, крупнее и с кольцом. Это работает только для звёзд из самой игры.
3. В подсказке системы появляется строка «● Отмечено в Debug Toolpack».

Пока система отмечена, игра видит у неё класс-копию звезды. Поэтому не держите отметки постоянно.

## Мультиплеер и права

- **ХОСТ.**
  - Команды «это хост партии» в скриптах игры нет.
  - Если игрок в партии один, ХОСТом становится он.
  - Если игроков несколько, ХОСТа выбирают единогласным голосованием остальных.
  - В шапке у ХОСТа видна метка «« ХОСТ »».
- **Права выдаёт и отзывает ХОСТ**, отдельно каждому игроку. Это делается во вкладке «Доступ».
- **Проверка прав настоящая.**
  - Игра сообщает кнопке, кто её нажал (`From`).
  - Права проверяются в момент выполнения, а не только при показе кнопки.
- Все изменения выполняются эффектами игры и синхронизируются у всех игроков.
- У каждого администратора свои A, B, планета и флот (до 16 администраторов).

## Что проверено и что ограничено

**Проверено в игре по `game.log`:**
- выбор целей;
- ресурсы;
- отметка через окно планеты (флаг ставится);
- список отмеченных;
- снятие отметки.

**Проверено в game.log и error.log; это ограничения движка:**
- Кнопки в значках галактической карты (звёзды, флоты, планеты и т. д.) получают от игры только империю игрока, а не объект. Поэтому клик по значку карты не может отметить систему. Отмечать нужно через окна планеты, звезды или станции.
- Клавиши NumPad 0–9 не распознаются (`KP_7` неизвестен). Работают цифры над буквами.

**Невозможно скриптами:**
- текстовое поле ввода и поиск по тексту;
- очередь строительства;
- «мир с итогом войны».

**Требует проверки в игре в версии 5.0:**
- переименование отмеченной системы;
- смена значка звезды;
- новые кнопки «Я»;
- «↻ Повторить»;
- новый вид окна целиком: размер 1100×720 на маленьких экранах, читаемость шрифтов, значки разделов.

Если что-то не работает, запустите игру с `-debug_mode` и пришлите `game.log` и `error.log`. Строки `DTP …` показывают каждый шаг.

## Совместимость
- **UI Overhaul Dynamic:** нужен патч (см. 10.5). Без патча и при UIOD ниже Toolpack окно Toolpack пропадёт.

- Мод заменяет четыре файла интерфейса игры: `main.gui`, `planet_view.gui`, `fleet_view.gui`, `starbase_view.gui`. Это копии файлов 4.5.2 с добавленными блоками Toolpack. Моды, которые меняют эти же файлы (например, UI Overhaul Dynamic), конфликтуют с Toolpack.
- Классы звёзд `dtp_mk_*` имеют нулевой шанс появления и в новой галактике не выпадают.
- Мод меняет контрольную сумму, поэтому у всех игроков должен быть одинаковый набор модов.
